PROJECT DESCRIPTION
WordWise is a responsive, single-page dictionary application. Users enter an English word and the app retrieves definitions, parts of speech, phonetic spelling, example sentences when available, and audio pronunciation when available.

API USED
Free Dictionary API
Documentation: https://dictionaryapi.dev/
Example endpoint: https://api.dictionaryapi.dev/api/v2/entries/en/hello
API key: Not required.

FILES
- index.html: Group portfolio homepage and member profiles.
- app.html: Dictionary application page.
- styles.css: Responsive design and styling.
- script.js: Fetch request, JSON parsing, results rendering, audio playback, input validation, and error handling.

HOW TO RUN
1. Keep all four project files in the same folder.
2. Open index.html in a modern web browser.
3. Click "Try WordWise" or "Open App".
4. Enter an English word and click Search.
5. Internet access is required to fetch live dictionary data.

GITHUB SUBMISSION
1. Create a new public repository on GitHub.
2. Upload index.html, app.html, styles.css, script.js, and this README.txt.
3. Replace all sample member names and bios with your actual group information.
4. Add each member's photo if required by your instructor. You can put image files in the same repository and update index.html.
5. Copy the repository URL for submission.
6. Optional: enable GitHub Pages in the repository settings to publish the website.

TECHNICAL NOTES
The app uses fetch() and async/await, checks HTTP responses, parses JSON, updates the DOM, validates user input, and displays user-friendly error messages for missing words and network problems.
